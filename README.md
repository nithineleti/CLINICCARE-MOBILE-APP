# ClinicCare Hospital Management System

## 🌐 Live Application
The application is deployed and available at the link below:
👉 **[http://cliniccare-hospital-v1.s3-website-us-east-1.amazonaws.com](http://cliniccare-hospital-v1.s3-website-us-east-1.amazonaws.com)**

## 🚀 Overview
A modern, interactive clinic management platform built with Expo (React Native) featuring specialized dashboards for:
- **Admin**: For clinic insights, specialty management, and department analytics.
- **Doctor**: Personalized schedules, patient analytics, and appointment tracking.
- **Patient**: Profile management and easy appointment access.

## ✨ Features
- **Interactive UI**: Soft-light teal theme with animated backgrounds.
- **Role-Based Access**: Specialized views based on user login.
- **Cross-Platform**: Optimized for Web and Mobile.
